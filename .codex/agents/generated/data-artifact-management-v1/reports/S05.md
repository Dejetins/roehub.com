## Implemented requirements

- **R02/R08:** bounded persisted-source discovery and initial base admission feed the
  actual managed worker. Initial base/precompute-on remain immediate. Durable source
  and schedule cursors survive reconstruction. Periodic observations collapse to a
  latest due occurrence; unverified source ranges coalesce into one containing target
  while original request snapshots remain unchanged. Frozen retry checks exact
  candle/funding content identity. Manual Update now preserves the cadence anchor.
- **R07:** common 1/3/7 calendar-day default, explicit instrument overrides and
  inherited default policies persist timezone, anchor, occurrence, next_due and
  successful completion. Subdaily values are rejected by the existing strict model.
  DST gap advances to the first existing civil minute; fold chooses its first
  occurrence. Internal maintenance does not override an organization's slower cadence.
- **R08/R13:** complete compatible groups share one physical build. Per-request
  authorization/catalog errors and insufficient derivative history are isolated.
  Mandatory base and eligible derivatives can publish while other requests wait.
  Bounded FIFO/round-robin organization/internal lanes, retry alternation, capped
  scans/group size, conservative effective-range storage admission and native limits
  prevent silent truncation and poisoned queue heads. Failed preclaim storage access
  has a durable reason. No fixed-time liveness takeover was introduced.
- **R09:** the actual native coordinator reports measured canonical/base/derivative
  stage/timeframe units. Persistent series retain monotonicity across interleaved
  phases; unknown totals stay unknown, observed timestamps/checkpoints are durable,
  retry starts a new epoch. Ready follows physical publication commit only.
- **R12/R13:** process lifetime starts before claim/retry visibility. Recovery must
  acquire that lifetime lock, validate an fsynced identity-bound receipt, current
  pointer generation/hash and canonical manifest before completing PG state.
  Unknown or corrupt publication outcomes remain quarantined; last-good/pin behavior
  continues through the existing physical publisher. Explicit owner-only handoff
  requires the legacy host lock/drain and imported-row coverage. Disabling managed
  capability cannot silently restart the legacy writer.
- **R04 compatibility:** frozen imported signal/risk choices are converted to exact
  native requests, without replacing legacy selections with today's default catalog.
  Actual scheduler factory selects the managed composition only through explicit
  `ROEHUB_ARTIFACT_MANAGEMENT_INSTALLATION_ID`, disabled legacy scheduling and trusted
  configured `backtest-primary` storage. It supplies the existing PG/ClickHouse,
  catalog, access, funding, publisher and host-lock adapters; construction performs
  no capability activation or implicit handoff.
