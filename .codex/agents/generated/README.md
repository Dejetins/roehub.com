# Historical prompt packs

Files in this directory preserve prior work and may supply evidence or context.
They are not a default execution queue and do not authorize a Goal, a stage, a
deployment, or access to a runtime target.

Use a pack only when the selected current ticket or its own current ledger
explicitly makes it authoritative. If a legacy prompt requires a retired
environment or contradicts the repository's current instructions, do not repair
or execute it in place: create or select a current ticket with an appropriate
proof boundary.
