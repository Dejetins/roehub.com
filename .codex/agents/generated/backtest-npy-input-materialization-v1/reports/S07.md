3. Independent review found a second disclosure channel in failed lazy-task `last_error`/`last_error_json`. The public materialization DTO now allowlists task metadata and uses constant failure text/code. Raw diagnostics remain persisted internally. HTTP failed-task regression tests cover trades GET/POST, equity, drawdown and CSV (202 safe task state); independent candles still return 200 without paths. Persisted diagnostics are rechecked after reads.

Tests extend existing owners: retain the four original in-process S06 scenarios and add four ordinary full-child/lazy-child HTTP scenarios; use real organizations and SQL isolation; force final post-build pointer/target mutation; test reordered canonical IDs `(100,20,37)`; add 72 independently prescribed financial cases with real generated NPY inputs.
