## Failed attempts and causal repair

All failed attempts are preserved separately and never pooled with revision 4. Generic/funding stage lifetime is unchanged and is outside this candle-throughput claim.

`writer-comparable-full.json` isolates the same full-data changed-value SQL with equal hashes: execution 1733 ms versus 2.913 ms, subject to ordered warm-cache limitations.
