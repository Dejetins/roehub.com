## Implemented boundaries

- Shared lifecycle-owned market gateways use `STRATEGY_PG_DSN`, the same database as
  control-plane publication fencing. Class-specific deadlines and admitted slots
  apply. Bounded DNS resolution preserves TLS hostname verification, refreshes on
  physical reconnect, supports IPv4/IPv6 and explicit hostaddr, and kills/reaps a
  timed-out resolver. A parent-death watchdog handles terminated WS writer children.
- REST fill acquires its generation/lease fence before provider I/O, renews while
  consuming rows and confirms/releases the same fence. Missing known origin never
  fabricates a verified frontier. Raw writes are capped8192; metadata/funding writes
  and reference lookup chunks are1000. Parquet scanning and RL transport are bounded;
  research rows are read-only anonymous memmaps, not an accumulated history list.
- Source targets require generation UUID, content revision and funding revision.
  Legacy targets fail validation/dispatch and migration0039 invalidates legacy work
  without deleting repair audit history. No equal-bounds or content_unverified bypass
  remains in activated source observation/reconciliation.
- Final publication holds source generation/revision guards across pointer switch
  and managed ready receipt using the same control transaction. Corrections, funding
  changes and generation resets during compute reject stale publication. Unpublished
  stale candidates can release exact-owner reservations; active interrupted pointer
  recovery still requires its recorded source identity. PG publication rebuilds the
  full base rather than reusing an unattested prefix. Hashing uses4096-row slices.
- Repair source/policy/hooks/metrics use `canonical_store`; SQLSTATE-based operational
  failures use stable `storage_*` codes. Additive0039 renames persisted audit source/
  errors while preserving audit IDs/timestamps. Alert/runbook names were updated.
  Application roles retain no partition DDL; maintenance pre-creates required months.
