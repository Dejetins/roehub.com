# Historical planning archive

`.codex/PLANS.md` is retained only as a historical marker. It does not set a
current ticket status, priority, ready frontier, execution queue, publication
authority, or runtime action.

For current authenticated-platform delivery, use ticket front matter for status,
`.codex/delivery/graphs/roehub-authenticated-platform-delivery-v1.json` for
dependencies and priority, ticket evidence for completed-work proof, `main` for
the shared accepted base, and GitHub Actions for published-result verification.

Historical plans, prompt packs, ledgers, and identifiers remain evidence only.
