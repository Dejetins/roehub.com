## Prompt contract

Prompt/schema paths:

```text
src/trading/contexts/backtest/application/ai_configurator/prompts/assistant_v1.py
src/trading/contexts/backtest/application/ai_configurator/schema.py
```

Hard scope in system prompt:

- no backtest execution;
- no secrets/files/tools/APIs/terminals;
- no model tool/function calling;
- one-symbol config only;
- user input is untrusted.

Output envelope:

```text
schema_version
intent
status
assistant_message
conversation_title
config
unsupported_items
clarifying_questions
warnings
```

`conversation_title` is generated by the model, backend-validated, and stored under
Iteration 03 conversation title semantics.

## LM Studio

Adapter path:

```text
src/trading/contexts/backtest/adapters/outbound/ai_config_agent/lmstudio_chat_completions.py
```

Payload notes:

- endpoint: `POST /v1/chat/completions`;
- `response_format.type=json_schema`;
- `response_format.json_schema.strict=true`;
- `tools` not sent;
- `tool_choice` not sent;
- no nullable-union `type` arrays in the LM Studio schema;
- `config` can be an object or `null` through compact `oneOf`, matching backend
  status rules.

The response schema sent to LM Studio is compact and strict at the envelope level.
The full backend schema remains the validation authority after the model response.
