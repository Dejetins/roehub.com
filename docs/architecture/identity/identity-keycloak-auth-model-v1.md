# Историческая модель аутентификации через Keycloak

Статус: `superseded`; синхронизировано с текущим wiring 2026-09-06.

Обязательный Keycloak и отсутствие локального входа описывали прежнюю модель.
Эти требования больше не являются контрактом текущего приложения.

Текущая реализация создаёт `LocalAuthService`; OIDC provider подключается
только при `settings.oidc_enabled`. Keycloak может быть одним из провайдеров
OIDC, но не является обязательной зависимостью установки.

Текущие источники:

- [Локальный вход, сессии и восстановление](local-auth-sessions-recovery-v1.md).
- [Опциональный OIDC provider](oidc-authentication-provider-v1.md).
- [Identity composition root](../../../apps/api/wiring/modules/identity.py).

История прежнего содержания доступна в Git. Этот документ не разрешает
миграцию пользователей, удаление локального входа или повторный cutover.
