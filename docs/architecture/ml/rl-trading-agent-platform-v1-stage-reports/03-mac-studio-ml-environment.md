# Stage 03: Mac Studio ML Environment

Статус: `accepted`.

User required before start: nothing unless a listed prerequisite is not accepted or a required credential/dataset/runtime source is unavailable; never ask for secrets in chat.

Stage `03` добавляет изолированный optional ML dependency path для PyTorch, фиксирует resource-isolation policy для Mac Studio и доказывает, что default API runtime не импортирует и не требует `torch`.

## Scope

Included:

- verify prerequisite Stage `02C`;
- add optional `rl-ml` dependency extra for PyTorch without adding `torch` to default dependencies or dependency groups;
- define disabled-by-default trainer/inference/backtest/disk resource policy for `dev`, `test` and `prod`;
- add a host-local CPU/MPS torch smoke that records wall time, CPU deltas, RSS, thread counts, MPS availability and accepted device policy;
- document Mac Studio operator commands and runtime artifact root `/opt/roehub/state/rl_trading/`;
- prove default API dependency isolation locally and on Mac Studio.

Not included:

- training user-owned custom models;
- creating datasets, checkpoints, raw tensors or model registry artifacts;
- enabling trainer or inference services;
- changing public API, UI, persisted schemas, live execution, exchange adapters, secret custody, paper/testnet/live/mainnet behavior or `ml_agent_decision` runtime production.

## Dependency And Runtime Policy

| Surface | Accepted policy |
|---|---|
| Dependency isolation | `torch>=2.7,<3` is available only through `uv sync --locked --extra rl-ml` / `uv run --extra rl-ml ...`; default `uv sync --locked` removes `torch`. |
| API runtime | API import path must not import or require `torch`; focused tests run in a default environment. |
| Device policy | MPS preferred with CPU fallback. If MPS is unavailable, Stage `03` allows CPU fallback and later Stage `07` must re-measure training throughput before accepting CPU-only training. |
| Trainer | Disabled by default; one concurrent job; prod cap `torch_num_threads=4`, `torch_num_interop_threads=1`, `max_rss_mb=32768`, `nice=10`. |
| Inference | Disabled by default; one process; prod cap `torch_num_threads=1`, `torch_num_interop_threads=1`, `max_rss_mb=4096`. |
| Backtest jobs | Prod allows one backtest job while training and two when inference-only; heavy job serialization must be enforced before trainer enablement. |
| Disk | Prod blocks training below `150 GiB` free and keeps `100 GiB` minimum free; cleanup cannot delete accepted artifacts. |
| Runtime artifacts | Datasets/checkpoints/raw tensors stay under `/opt/roehub/state/rl_trading/` and are not committed. |
