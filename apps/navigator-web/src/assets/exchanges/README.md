# Exchange identifiers

Local copies of exchange-owned brand assets, retrieved 2026-10-04 for identifying
market sources in Data Navigator. These are trademarks of their respective owners.
No runtime requests to exchange websites are required.

- `binance.ico`: unmodified 32x32 official website icon from
  https://bin.bnbstatic.com/static/images/common/favicon.ico
  (Binance static asset CDN; official media page https://www.binance.com/en-GB/press).
- `bybit.svg`: unmodified white/orange logo embedded as an SVG image in the header
  of https://www.bybit.com/en/press. Decoded from the page's image data URI.
